Gestión Comercial

Sistema de Facturación Comercial (Empresa Ropa)

Desarrollo e implementación de un modelo de factura automatizada y cálculo de compras corporativas. Diseñado para optimizar los procesos de cobro, control de inventario y registro de transacciones.

Código fuente (Python):

import os
os.system("cls")
print("Bienvenido al sistema de factura de la empresa Ropa")

cliente = "Santiago Vergara"
np = "Jean"
pp = 3000
cp = 3
nc = "Camisa"
pc = 2000
cc = 5

sc = pc * cc
sp = pp * cp
pdc = 10
pdp = 20
vdc = sc * pdc / 100
vdp = sp * pdp / 100
total = (sp - vdp) + (sc - vdc)
piva = 16 / 100
iva = total * piva

print("Subtotal:", (sp + sc))
print("Total a pagar:", total + iva)
